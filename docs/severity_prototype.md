# 파각 정도(심각도) 프로토타입 — AI Hub 약한 라벨 (2026-10-09)

## 목적
교수님 우선 과제 "기기 영상으로 정상란/파각란 분류 + 파각 정도(심각도) 도출" 대비.
자사 라벨이 아직 없으므로 AI Hub MONO 크랙 소분류 코드를 3등급으로 묶은 **약한 라벨**로,
분류기가 영상에서 "정도"를 구분할 수 있는지 먼저 확인했다. 자사 영상이 오면 `docs/labeling_guide.md` 의 severity 1~3 라벨로 재학습한다.

## 등급 매핑 (`configs/exp_sev_mono.yaml`, 코드→이름은 가설)
| 등급 | 소분류 코드 | 근거 |
|---|---|---|
| 1 경미 | 2/6 잠재파형, 2/8 미세 | 개수로 확인된 코드 (3,930 / 6,931) |
| 2 보통 | 2/2 일자형, 2/3 원형, 2/4 위아래, 2/7 파형 | 문서 순서 가설 |
| 3 심각 | 2/1 완전, 2/5 거미줄형 | 문서 순서 가설 |

설정: EfficientNet-B0, 320px, weighted CE, label smoothing 0.05, 6 epoch, (촬영일·지역) 그룹 분할.
train 32,117 / val 5,373 / test 7,048 크롭. 실험 폴더 `experiments/20261009_173953_sev_mono_effb0/` (학습 로그는 `20261009_165531_sev_mono_effb0/`).

## 결과 (test, 갈색란·MONO 만)
| 등급 | n | Recall | Precision | F1 |
|---|---|---|---|---|
| 1 경미 | 1,110 | 0.622 | 0.519 | 0.566 |
| 2 보통 | 5,173 | 0.853 | 0.909 | 0.880 |
| 3 심각 | 765 | 0.886 | 0.787 | 0.833 |

- 정확도 0.820, macro Recall 0.787
- **인접 등급 허용(±1) 정확도 0.991**
- 심각(3) → 경미(1) 오분류 2.9%, 경미(1) → 심각(3) 오분류 3.8%

혼동행렬 (행 = 실제, 열 = 예측):

| | 1 | 2 | 3 |
|---|---|---|---|
| 1 | 690 | 378 | 42 |
| 2 | 618 | 4,413 | 142 |
| 3 | 22 | 65 | 678 |

그룹별 macro Recall: 품종 1 → 0.807 (n=398), 품종 2 → 0.726 (n=906), 품종 3 → 0.794 (n=5,744) / 지역 32400 → 0.878, 35370 → 0.751, 37380 → 0.807, 38390 → 0.726 (세척여부는 MONO 단일값이라 비교 불성립). 지역·품종 간 편차가 있으므로 자사 데이터에서는 난각색별로 따로 봐야 한다.

지연 (RTX 4060, FP16): batch 1 → 7.1 ms, batch 16 → 0.78 ms/장.
`eval.json` 의 `operating_points` 항목은 크랙 vs 정상 전용 계산이라 이 실험에서는 의미 없음(무시).

## 해석
1. 혼동은 거의 **경미 ↔ 보통** 사이에서 생긴다(경미 Recall 62%). 코드 기반 약한 라벨 자체가 "정도"와 정확히 일치하지 않는다(파형 크랙 중에도 작은 것이 있음). 양 극단(경미 vs 심각) 혼동은 3~4%로 작아, 영상에 등급 정보가 담겨 있다고 볼 수 있다.
2. 결론: **심각도 헤드는 가능**. 서비스용 등급은 자사 영상에서 사람이 매긴 severity 라벨로 재학습해야 한다. 설명 가능성을 위해 빛샘 영역 물리 지표(길이·면적·밝기)와 결합하는 것이 다음 후보(`docs/upgrade_candidates.md` A3).
3. 흰색란은 AI Hub 에 없으므로 흰색란 성능은 자사 데이터로만 확인 가능.

## 운영 메모
- 평가 단계에서 DataLoader 워커(8개)가 "페이징 파일이 너무 작아" 오류로 죽어 메인 프로세스가 멈췄다(웹 서버 동시 실행 중, RAM 15GB). 저장된 체크포인트로 `epochs=0 init_from=... workers=4` 평가만 다시 실행해 결과를 얻었다. **이 PC 에서는 workers ≤ 4 권고.**
- `src/train/classifier.py` 에 epochs=0 + init_from 평가 전용 경로 추가.
