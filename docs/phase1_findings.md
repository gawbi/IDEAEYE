## 분할 설계에 영향을 주는 분포

- **촬영일**: MONO 는 2022-05~07 에 걸쳐 있으나 2022-05-11 하루가 16,839판(27%). COLOR 는 5일뿐(09-07, 09-13, 09-19, 10-06, 10-07). → 촬영일 단독 group split 은 COLOR 에서 분할 5개 덩어리로만 나뉨.
- **지역코드**: MONO 는 32400 이 78%. COLOR 는 2개 지역(34310, 37380). → 지역코드를 그룹 키로 쓰면 성분이 거대해짐. `group_mode: connected` 는 부적합, `combined`(촬영일×지역 조합) 또는 판 단위로 가야 함.
- **세척여부**: MONO 62,353 : 300 으로 사실상 단일값 → "세척/비세척별 성능"은 COLOR(31,635 : 16,843)에서만 가능. 어느 코드가 세척인지 미상.
- **품종**: COLOR 는 전부 코드 1, MONO 는 코드 3 이 87%.
- MONO 410판은 category 결측 — 모델 설명서의 "N/A 클래스"와 관련 가능성.
