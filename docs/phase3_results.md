## 3. 운영점 (MONO, 양성=크랙 state 2, 음성=정상 state 1)

| 파각 Recall 목표 | 임계값 | 정상란 오검출률 |
|---|---:|---:|
| 90% | 0.221 | 15.8% |
| 95% | 0.055 | 35.7% |
| 98% | 0.011 | 66.3% |

→ 33클래스 softmax 의 크랙 확률 합은 운영점 용도로 날카롭지 않다. 후속 실험(2026-09-25) 결과:

| 모델 | Recall 90% | Recall 95% | Recall 98% | 비고 |
|---|---:|---:|---:|---|
| 33 소분류 (베이스라인) | 15.8% | 35.7% | 66.3% | |
| 33 소분류 + weighted focal | 14.0% | 29.4% | 55.0% | ablation 최선 |
| 대분류 6클래스 | 17.0% | 38.7% | 65.1% | 도움 안 됨 |
| **크랙 vs 정상 2클래스 (320px, 8ep)** | **2.9%** | **9.6%** | **22.6%** | 배출 판정 전용 헤드로 채택 |

**결론: 배출 판정은 2클래스 전용 헤드로, 소분류 보고(미세크랙·잠재파형 등)와 검란은 33클래스 모델로 분리 운용한다.** 2클래스 모델의 음성은 정상(state 1)만이므로, 실제 라인에서는 탈색·이물질 등 다른 결함 크롭도 유입된다. 다음 단계에서 3클래스(정상/크랙/기타결함) 또는 2클래스 음성에 기타 결함을 포함한 재학습으로 확인해야 한다.

## 4. 세척 / 품종 / 지역별

- MONO: 세척 코드가 62,353:300 으로 사실상 단일 → 비교 불가. 지역코드별 FN율(Recall95 운영점): 32400 6.1%, 35370 4.7%, 37380 2.5%, 38390 5.7%.
- COLOR: 촬영일 기준 분할에서는 test 가 단일 촬영일·단일 세척코드(2) → 비교 불가. 세척 비교 전용 판 단위 분할(`index_color_wash.csv`, 촬영일 누수 허용)로 재학습한 결과(2026-09-25, acc 0.932): **세척 코드가 클래스와 완전히 얽혀 있어 비교가 성립하지 않음**. 세척 1 test 에는 정상이 37개뿐(크랙 2,103개), 세척 2 test 에는 크랙이 32개뿐(정상 11,376개). 즉 세척 1 = 10월·결함 위주 촬영 세션, 세척 2 = 9월·정상 위주 세션이라 "세척 효과"와 "촬영 세션/클래스 분포"를 분리할 수 없다. 이 실험의 낮은 FPR(0.2%)은 세션 단서 학습 가능성이 있어 KPI 로 쓰지 않는다. **세척별 성능 비교는 자사 데이터에서 세척/비세척을 같은 세션에 섞어 촬영해야 가능하다.**
