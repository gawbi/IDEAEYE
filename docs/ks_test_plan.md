# KS B 7956-4 기준 내부 시험 계획안 (파각란검출기)

작성 2026-10-09 · 목적: 공인 시험 전에 같은 기준으로 자체 평가하고, 시험 조건이 명시되지 않은 부분(배치 구성·수량)을 기업·교수님과 합의하기 위한 초안.

## 1. 기준
- 측정 기준: **파각란 미검출 비율 7% 이내** = 검출기를 통과해 정상으로 배출된 계란 중 파각란의 비율.
- 표준에 최소 시험 수량·배치 구성 기준 없음 → 아래 2절을 제안.

## 2. 제안 시험 조건
| 항목 | 제안 | 이유 |
|---|---|---|
| 시험 수량 | 정상란 500 + 파각란 100 (총 600) 이상 | 미검출 비율 7% 를 유의하게 판정하려면 파각란 100개 이상 필요 |
| 파각란 구성 | 미세(심각도 1) 40 / 보통 40 / 심각 20 | 미세크랙이 어려운 유형이므로 비중을 높여 보수적으로 |
| 난각색 | 흰색·갈색 각 절반 | 둘 다 대상 |
| 도장 | 도장 있는 계란 절반 이상 | 현장 조건 반영 |
| 라인 조건 | 실제 운용 속도, 3회 회전 촬영, 카메라 2대 | 운용 조건과 동일 |
| 반복 | 같은 배치를 3회 통과(계란을 섞어서) | 시점 변동에 의한 편차 확인 |

## 3. 산출 지표 (운용 기준과 함께 보고)
- KS 미검출 비율 = 통과한 계란 중 파각란 수 ÷ 통과한 계란 수
- 파각 Recall(= 1 − 파각란 중 놓친 비율), 정상 오배출률(정상란 중 배출된 비율)
- 심각도별 Recall, 난각색별·도장 유무별 Recall
- 처리 속도(계란 1개당 ms, 시간당 개수)

## 4. 판정 임계값 설정 절차
1. 라벨된 자사 데이터의 test 분할에서 시점별 점수 분포를 얻는다.
2. 3시점 융합 규칙(`src/infer/voting.py`)을 적용해 최종 Recall ≥ 95% 를 만족하는 임계값 중 정상 오배출이 가장 낮은 값을 고른다.
3. 위 2절 배치로 실기 시험 → 미검출 비율과 오배출률 기록 → 필요 시 임계값 조정 후 재시험.
4. 확정 임계값은 `configs/infer.yaml` 과 서버 설정(버전·설정 시각)에 기록 → KS 송출 "설정 시간"과 연결.

- "파각란"의 정의 범위(미세 균열 포함 여부)와 심각도 기준의 공식 해석
