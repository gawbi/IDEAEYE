# 라벨링 가이드 — 파각란검출기 영상 (자사 데이터)

대상: 캡스톤 팀 라벨링 담당자. 도구: `python scripts\label_crops.py <index.csv>` (키보드 라벨링). 영상 → 크롭은 `scripts\ingest_video.py` 가 만든 `data/own/frames/<영상>/index.csv` 를 사용.

## 1. 라벨 항목 (index.csv 열)

| 열 | 값 | 설명 |
|---|---|---|
| `label` | `normal` / `crack` / `unsure` / `empty` | 이 크롭(한 시점)에서 보이는 것 기준. 크랙이 **이 사진에서 보이지 않으면 normal** (다른 시점에서 보일 수 있음 → 계란 단위 라벨은 3시점을 합쳐 자동 계산). 계란이 없거나 반 이상 잘렸으면 `empty` |
| `severity` | `1` / `2` / `3` (crack 일 때만) | 1 = 미세(가는 선, 빛샘이 희미, 주의해서 봐야 보임) · 2 = 보통(선이 뚜렷, 빛샘이 분명) · 3 = 심각(구멍·넓은 빛샘·껍질 변형) |
| `shell_color` | `white` / `brown` | 난각색. 투광 색이 아니라 껍질 색 기준 (흰색란도 투광하면 주황으로 보임) |
| `stamp` | `y` / `n` | 잉크 도장이 크롭에 보이는지. 크랙과의 혼동을 분석하기 위한 메타 |
| `note` | 자유 | 예: `도장 위 크랙`, `컵에 가려짐`, `흔들림` |

## 2. 판단 기준

- **크랙의 모양**: 투광 상태에서 껍질 틈으로 빛이 새어 **밝은 선·점·그물** 로 보임. 껍질 표면의 반점(점박이, 칼슘 침착)은 어둡거나 색이 다르고 선형이 아님 → normal.
- **도장 글자**: 초록/파랑 잉크의 글자·숫자. 크랙이 아님. 글자 위를 지나는 밝은 선이 있으면 crack + note `도장 위 크랙`.
- **반사·하이라이트**: 컵 테두리 반사나 카메라 쪽 LED 반사는 크랙이 아님(위치가 매 프레임 같음).
- **확신이 없으면 `unsure`**: 억지로 normal/crack 을 고르지 말 것. unsure 는 학습에서 제외하고 나중에 재검토.
- 심각도는 **빛샘의 길이와 폭** 기준: 계란 높이의 1/4 미만이고 가늘면 1, 1/4~1/2 또는 뚜렷하면 2, 그 이상·구멍·다중 균열이면 3.

## 3. 작업 순서

1. 영상 반입: `python scripts\ingest_video.py "<영상 폴더>"` → `data/own/frames/<영상>/index.csv`
2. 라벨링: `python scripts\label_crops.py data\own\frames\<영상>\index.csv` — 키: `n` normal · `c` crack · `u` unsure · `e` empty · `1/2/3` 심각도 · `w/b` 난각색 · `s` 도장 토글 · `←/→` 이동 · `q` 저장 종료. 저장은 자동(매 입력마다 CSV 갱신).
3. 통합: `python scripts\own_build_index.py` → `data/own/index.csv` (학습 입력). 같은 계란의 3시점은 같은 그룹으로 묶여 train/test 가 섞이지 않도록 분할됨.
4. 계란 단위 라벨은 자동: 3시점 중 하나라도 crack 이면 계란 = crack, 심각도는 최대값.

## 4. 수량 목표 (1차)

| 구분 | 최소 | 비고 |
|---|---:|---|
| normal 크롭 | 600 | 흰색·갈색 각각 절반 이상 |
| crack 크롭 | 300 | 심각도 1(미세)이 최소 100 |
| unsure | 제한 없음 | 재검토 큐 |

라벨링 속도 기준: 숙련 후 크롭당 3~5초 → 1,000장에 약 1시간.

## 5. 품질 관리

- 2명이 같은 100장을 독립 라벨링해 일치율을 확인(목표 90% 이상). 불일치는 함께 보고 기준을 수정해 이 문서에 반영.
- 모델 1차 학습 후, 모델과 라벨이 다른 크롭을 우선 재검토(라벨 오류 발견용).
