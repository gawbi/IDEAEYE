# 자사 라인 데이터 수집 요청서 (파각 검출·검란 AI 개발용)

작성: 2026-09-26 · 목적: 공개 데이터(AI Hub)로 만든 모델을 자사 선별기 환경에 맞추기 위한 데이터. 아래 조건을 지켜 촬영·전달해 주시면 받은 즉시 평가와 미세조정에 들어갈 수 있습니다.

## 1. 꼭 지켜야 할 것

| 항목 | 요청 | 이유 |
|---|---|---|
| 조명 | **투광(백라이트) 영상 필수**. 반사광 카메라가 있으면 같은 판을 함께 촬영 | 크랙과 혈반·먹통 판정을 투광 한 장으로 처리하는 구조. 반사광은 이물질·외형 검사 확장용 |
| 원본 유지 | 카메라 원본 해상도, 무압축 또는 고화질 JPEG(품질 95 이상), 리사이즈·크롭·자동 보정 금지 | 미세크랙은 가는 선이라 압축·축소에 사라짐 |
| 촬영 단위 | 선별기 위 **판(트레이) 단위** 그대로. 계란을 따로 꺼내 찍지 말 것 | 실제 운용 조건과 같아야 함 |
| 계란 회전 | 계란이 이동 중 회전한다면 **같은 계란을 3~5프레임 연속 촬영** (프레임 간격 기록) | 단일 시점에서 안 보이는 균열이 많음(공개 데이터 분석 결과). 다중 프레임 투표로 정확도 상승 |
| 세척 조건 | 세척란·비세척란을 **같은 날, 같은 카메라 설정으로 섞어** 촬영 | 세척 효과와 촬영일 효과를 분리해야 함 (공개 데이터는 얽혀 있어 비교 불가였음) |
| 조명 참조 | 계란 없이 빈 판(또는 확산판)만 찍은 사진 5장 이상, 촬영 세션마다 | 조명 불균일(flat-field) 보정용 |
| 메타 정보 | 촬영일시, 카메라 기종·해상도·fps·노출, 조명 종류, 라인 속도(시간당 개수), 품종·난각색, 세척 여부 | 조건별 성능 분석과 배포 설계에 필수 |

## 2. 장수 (최소 → 권장)

| 구분 | 최소 | 권장 | 비고 |
|---|---:|---:|---|
| 정상 | 판 100장 | 판 300장 | 계란 약 1,000~3,000개 |
| 크랙 (미세·잠재 포함) | 계란 200개 | 계란 500개 이상 | 미세크랙은 별도로 최소 100개. 어떤 크랙인지 메모 |
| 혈반·육반 | 계란 50개 | 계란 200개 | 희소하므로 있는 대로 모두 |
| 먹통·기타 결함 | 계란 50개 | 계란 200개 | |
| 빈 판 / 확산판 | 5장 | 세션마다 5장 | |

라벨이 없어도 **사진만 먼저** 보내 주시면 zero-shot 평가(현재 모델이 얼마나 맞는지)를 바로 할 수 있습니다. 라벨은 그 다음이어도 됩니다.

## 3. 라벨 규칙 (라벨링을 하실 경우)

- 계란마다 bbox + 상태. 상태 분류는 AI Hub 소분류 체계를 따름: 정상 / 크랙(완전·일자형·원형·위아래·거미줄형·잠재파형·파형·미세) / 혈반·육반 / 먹통 / 중앙기실 / 알끈 / 거품 / 탈색 / 이물질 / 기형.
- 애매하면 "크랙(유형 모름)" 처럼 대분류만 적어도 됨. 틀린 소분류보다 대분류만 정확한 것이 낫습니다.
- 좌표는 이미지 좌상단 원점(일반 이미지 좌표). 도구는 LabelImg·CVAT·Roboflow 등 아무거나, 형식은 YOLO txt 또는 PASCAL VOC xml.

## 4. 전달 방법

- 폴더 구조 예: `날짜_라인/투광/판번호.jpg`, `날짜_라인/반사광/판번호.jpg`, `날짜_라인/meta.csv`
- 파일명에 판 번호와 프레임 번호를 넣어 주세요(예: `20261001_L1_T0034_f2.jpg`).
- 압축(zip)해서 전달. 용량이 크면 외장 저장장치나 클라우드 링크.

## 5. 같이 알려 주셔야 할 현장 정보

카메라 기종·해상도·fps, 조명 종류(파장·광량), 계란 회전 여부, 시간당 처리량과 계란 1개당 허용 지연, 추론 장비(Jetson / 산업용 PC + GPU), PLC 기종과 통신 방식(Modbus TCP 등), 배출 방식(판 내 위치 지정 방법), 배출 대상 결함 정책(크랙만 / 크랙+혈반 / 전부), 목표 검출률과 허용 오배출률.
